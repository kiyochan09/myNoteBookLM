# ScanLight

スキャン画像を主体とするPDFをブラウザ内で圧縮します。ファイルの送信は行いません。PDF処理ライブラリは同梱しています。

## 使い方

Node.jsがあるWindowsで「起動.cmd」を実行し、ブラウザが接続するまで少し待ってください。PDFを選択し、高画質（200 dpi）、バランス（150 dpi）、最小サイズ（96 dpi）を選び、プレビューを確認して圧縮します。処理後にPDFを保存してください。終了時はサーバーのウィンドウを閉じてください。

## 仕様

- 1ファイル200 MBまで。各ページを順にJPEG化し、PDFを再構成します。
- 元のページ数、表示上の用紙サイズ・向きを保持します。
- 画素数の上限は1ページ1600万画素です。大判ページは設定より低い解像度になる場合があります。
- OCR検索テキスト、注釈、リンク、フォーム、電子署名は保持しません。
- 圧縮率は内容に依存します。小さくならない場合は元のファイルをダウンロードします。
- パスワード付きPDFには対応しません。
- 大きな文書は端末のメモリ制約で失敗する場合があります。

## 検証状況

JavaScriptの構文と、同梱PDFライブラリによる縦横2ページの生成・読み込み・サイズ確認は成功しました。この作成環境ではローカル接続がタイムアウトしたため、画面操作と実際の画像圧縮を通したブラウザ検証は未完了です。
