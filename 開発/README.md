# 開発用フォルダー

開発作業の運用方針は [AGENTS.md](../AGENTS.md) を参照。

- `作業中/YYYY-MM-DD_作業名/`：進行中の修正、調査、試験、検証用ファイルをまとめる。
- `履歴/YYYY-MM-DD_作業名/履歴.md`：完了後に、最終変更・検証結果・反映状態・バックアップ先などの最低限の記録を残す。
- `履歴/既存の修正記録/`：今回の整理以前に作成された修正記録。

完了した作業フォルダーは削除する。大きな試験データやソースコピーを履歴へ移さない。

引き継ぎメモは `../引き継ぎメモ/`、ユーザー向け成果物は原則 `../成果物/` に置く。成果物の確認と削除はユーザーが行う。
